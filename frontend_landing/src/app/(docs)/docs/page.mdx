# CloudLedger guide

<p className="lead">CloudLedger connects to your cloud accounts, finds wasted spend, and explains every number with the data behind it. This guide explains how each part works, in plain language.</p>

CloudLedger is a read-only cloud cost platform for AWS, Azure and Google Cloud. You connect
an account, and CloudLedger reads cost and usage data, groups it, and lists what looks wrong.
Fixes are suggestions. Nothing changes on its own.

## Two things to know before anything else

1. **Read-only by default.** CloudLedger never needs permission to change, delete, or create
   resources. You grant access through a role you can revoke at any time.
2. **Every number has a source.** Each finding links to the resource, metric, and time window
   that produced it. When the data does not support a claim, CloudLedger says so.
