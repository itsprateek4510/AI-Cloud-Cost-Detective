## The access model

CloudLedger reads cost and usage data through a read-only role in the customer's cloud
account. The guiding rules:

- Access is read-only. No write permission is requested.
- The customer can revoke access by deleting the role.
- Findings are computed from cost and usage data, not from application data.
- AI explains and prioritises. It does not produce the savings numbers.
- Nothing is changed automatically. Fixes are suggestions.

## Adding a docs page

1. Create `docs/<slug>/page.mdx` under `src/app/(docs)`.
2. Add the page to `src/lib/docs-nav.ts` with a title, description, and group.
3. Use `<span className="docs-badge">Coming soon</span>` for anything that is not live.

The sidebar, search index, and overview cards read from `docs-nav.ts`, so no other file needs
to change.
